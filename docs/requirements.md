# costly-py 要件定義書

## 1. 概要

現役調理師としての「原価率管理」の実務経験を、家計管理（食費・生活費）に
応用したパーソナルファイナンスアプリ。COSTLY（Java/Spring Boot版）の
コンセプトを継承し、Python/FastAPIで新規に実装する。

RaiseTech初級編 最終課題として、要件定義〜AWSデプロイまでを自力で実施する。

## 2. 背景・目的

- 開発者は老人ホーム厨房の店長として、原価率74.5%管理の実務経験を持つ
- 「支出を原価、収入を売上」に見立て、家計にも同じ管理手法を応用できると考えた
- IT転職ポートフォリオとして、実務経験と技術力を結びつけて示す

## 3. 技術スタック

| 領域 | 技術 |
|---|---|
| バックエンド | Python 3.x + FastAPI |
| フロントエンド | Jinja2（サーバーサイドレンダリング）+ Tailwind CSS |
| DB | MySQL 8.0 |
| ORM | SQLAlchemy |
| インフラ | AWS EC2 + Terraform |
| バージョン管理 | Git / GitHub |

## 4. 機能要件（スコープ）

### 4.1 コア機能（必須）

- 支出登録：費目・金額・日付を入力し、記録する
- ダッシュボード：
  - 生活防衛力（＝支出 ÷ 収入 × 100）を算出・表示
  - 目標比率とのギャップ表示
  - 今月の総支出・費目別の内訳表示

### 4.2 将来拡張（スコープ外・任意実装）

- メダル制度（週間チャレンジ達成でメダル獲得）
- コーチキャラによるフィードバック
- 進化キャラ（SVG、メダル数に応じて成長）

これらはCOSTLY（Java版）で構想済みだが、今回は開発期間の都合上、
コア機能の完成を優先し、余裕があれば着手する。

## 5. 画面構成

1. トップ画面：アプリ概要・登録画面への導線
2. 支出登録画面：費目・金額・日付の入力フォーム
3. ダッシュボード画面：生活防衛力の可視化

## 6. データモデル（案）

### Expense（支出）テーブル

| カラム名 | 型 | 説明 |
|---|---|---|
| id | INT (PK) | 主キー |
| category | VARCHAR | 費目（食費、光熱費など） |
| amount | INT | 金額 |
| date | DATE | 支出日 |
| created_at | DATETIME | 登録日時 |

### Income（収入）テーブル

| カラム名 | 型 | 説明 |
|---|---|---|
| id | INT (PK) | 主キー |
| amount | INT | 月収 |
| month | VARCHAR | 対象月（例：2026-09） |

## 7. 非機能要件

- AWS EC2上でのHTTPS公開（CloudFront経由）
- 個人情報（金額等）を扱うため、DB接続情報は環境変数化しGit管理から除外する
- レスポンシブ対応（スマホ・PC両方で閲覧可能）
